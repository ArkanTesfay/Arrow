# Vertex

**Vertex** is an open-source, AI-first code editor built on the MIT-licensed [Visual Studio Code - OSS](https://github.com/microsoft/vscode) codebase, part of the [Arrow](https://github.com/ArkanTesfay/Arrow) project. Our goal is the cleanest, fastest, AI-powered coding experience.
