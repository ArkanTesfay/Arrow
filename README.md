# Gooq

**Gooq** is an open-source, AI-first code editor, part of the [Arrow](https://github.com/ArkanTesfay/Arrow) project. Our goal is the cleanest, fastest, AI-powered coding experience.

## Highlights

- Full-featured editing on an MIT-licensed base: IntelliSense, debugging, Git integration, remote development
- Built-in AI chat, inline edits and completions, plus a dedicated Agents workspace
- Modern UI with a charcoal + warm gold design system
- Extensible via the Open VSX extension marketplace
